# V2 Integrated Module Hub

The V2 module hub loads the original learning pages inside the V2 interface using same-origin iframes. This preserves the original modules and avoids rewriting or deleting them.

Included: Book 1, Book 2, vocabulary hub, nouns, verbs, adjectives, adverbs, numbers, greetings, sentences, reading guide, EPS keywords, command/interview/sign/tools skill tests, EPS/DMW, guide, and help.
