# VIZKOR V2 Module Merge

This V2 update integrates the existing educational modules inside the V2 interface while leaving the root/original site files unchanged.

Integrated in-app module hub:
- Book 1 / Book 2 vocabulary
- Vocabulary hub
- Nouns, verbs, adjectives, adverbs
- Numbers, greetings, sentences
- Reading guide and EPS keywords
- Skill tests: command, interview, signs, tools
- EPS/DMW, guide, and help pages

The original pages remain the source of truth and are loaded same-origin inside V2, so their existing features continue to work without rewriting or deleting the originals.
